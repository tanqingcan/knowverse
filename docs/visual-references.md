### 版权提醒（重要）

- 《小王子》的文字与插画在多数国家**仍受版权保护**（法国等地因战争延展较久），**不要直接使用原作插画或官方 / 粉丝 3D 模型**。Meshy 等站上的「Little Prince」模型多为 AI / 粉丝生成，不能作为商用素材。
- 正确做法：**借鉴风格**（手绘、低饱和、圆润、纸感），用 CC0 / 商业许可包 + 程序化生成，保持原创。参考：[Le Petit Prince 版权复杂性](https://www.ccdigitallaw.ch/copyright-on-the-work-le-petit-prince-by-antoine-de-saint-exupery-the-complexity-of-the-different-national-copyright-laws-on-an-international-level/)。

### 怎么把现有模型调成「小王子感」

1. 材质：哑光 + 手绘 / 水彩纹理（或顶点色 + 轻微噪声），降低饱和度。
2. 轮廓：加一层很淡的描边 / 纸纹（不要卡通粗描边）。
3. 天空：粉彩渐变（已做）+ 柔光；避免纯黑深空。
4. 构图：微缩舞台 / 星球，物件尺度略夸张、圆润。
5. 仍按 §三 的复杂度预算减面。

## 三、素材复杂度预算

> 以「软件渲染 ≥12fps、GPU 60fps、单星球 13 株植物」为基线。

| 类别 | 单件三角面上限 | 贴图 | 备注 |
|---|---|---|---|
| 花（含花苞 / 开花） | ≤ 800 | 顶点色或 ≤256² | 优先程序化 / 极低模 |
| 树 | ≤ 2,000 | ≤512² | 远景用 LOD |
| 椅子 / 家具 | ≤ 500 | 顶点色 | 可实例化 |
| 旅人 | ≤ 2,500 | ≤512² | 可无骨骼 / 简单姿态 |
| 通用装饰 | ≤ 500 | 顶点色 | 实例化 |
| **单星球装饰总量** | **≤ 50,000** | 纹理总 ≤ 8MB | 超过则降级 / LOD |

**负荷（load）机制**：每件装饰记 `load = 三角面 / 1000`，星球总负荷封顶（例如 50）。放不下时提示「这个星球太满啦」。这既保护性能，也是「差异化」的一部分（每个人取舍不同）。

## 五、关键建议：成长渐变用 shader，不要找「成长动画模型」

「花要那种成长渐变形的」——现成的「花从种子长到开花」的 **GLB 动画模型很少，而且通常面数高 / 带骨骼**。更稳的做法：

1. 用任意**静态低模花**（≤800 面），在顶点着色器里做 **grow 参数 0→1**：
   - 沿局部 Y 缩放 + 轻微噪声错峰（每株 seed 不同）；
   - 花瓣 `open` 参数控制张开；
   - 颜色从「嫩绿 → 花色」插值。
2. 与现有 `Flower3D` 的 `open` / 阶段模型融合：把「生叶 → 花苞 → 开花」做成同一 mesh 的连续 morph，而不是换模型。
3. 这样素材复杂度可控、风格统一，也不需要下载带骨骼的动画。

参考实现：[Digital Petals（three.js 极坐标花 shader）](https://raw.githubusercontent.com/pulkitxm/claude-directory/7da39a2c9ab55b0d5869715d3b6cfdcc2045fd48/shaders/digital-petals-shader/README.md)、[VoxelTreeMorph](https://github.com/azidancorp/VoxelTreeMorph)。
