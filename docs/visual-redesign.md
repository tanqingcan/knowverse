# 视觉与交互重构：3D 绘本微缩世界

> 本次重构只改前端表现层。数据库、API、学习状态规则、历史检索、练习与判题逻辑都没有改动（`npm test` 47 个集成用例照常通过）。

## 1. 构图

- **固定的最佳角度**：花园建在星球北极的“球冠”上，镜头约 38° 俯视（3/4 视角），主花圃正对镜头。下半球被画面裁掉，不再出现一个巨大的灰绿色球体。
- **有限拖动**：左右约 ±34°、俯仰少量；拖动后出现“回到花园视角”，一键复位。没有连续自转，不会转到背面。
- **布局**：本命花所在花圃位于正中（本命花在花圃中心，带木牌）；资料温室在左后，星灯书屋在右后，回忆小径连接主花圃与书屋，长椅与小路灯在右侧，旅人坐在长椅上；远处的小星球是共学入口。布局只由花圃与植物的顺序决定（`src/components/world/layout.ts`），与数据库里旧的经纬度无关，保证构图稳定。

## 4. 两种模式

- **花园模式**（`/space`，或打开植物档案时）：星球是主角。顶部极简导航（花园 / 学习 / 回顾 / 资料 / 共学）、一条“今日建议”、底部场景入口工具栏（书屋·学习、温室·资料、小径·回顾、花圃列表）、左下角收起的时间轴（只显示最近一次变化）。选中花朵时档案在右侧纸张卡片中打开，花园仍可见。
- **专注学习模式**（对话、练习、学习卡、历史、时间轴、资料、共学）：右侧宽阅读区，内容居中、最大宽度约 880px；花园缩成左侧小场景（手机上隐藏），一键“回到花园”。

场景映射：温室 → 资料；书屋 → 学习与对话；回忆小径 → 历史问答；花圃 → 知识点档案；远处星球 → 共学。场景物体可点击，所有入口在普通导航与工具栏中也都有对应按钮，键盘可达（花圃列表支持 Tab / Enter / Esc）。

## 5. 动画（只有三段）

1. **进入花园**：镜头从远处靠近，书屋灯光逐渐亮起，主花圃进入视野。可点击或按键跳过；第一次约 2.6 秒，之后约 1.1 秒；慢设备上最多 4.2 秒。
2. **选择花朵**：选中圈、镜头轻移（避开侧卡 / 底部抽屉），旅人走到花圃旁照料，星灯飞过去，档案打开。
3. **独立验证完成**：只在后端保存成功、返回真实的阶段变化事件之后播放——少量光点沿回忆小径汇入花圃，旧阶段模型收起、新阶段模型弹出（开花时花瓣展开），旅人庆祝；随后出现简短反馈卡片与“查看这次成长”入口。

没有任何随机开花动画。`prefers-reduced-motion` 或设置中的“低动效”：无入场与镜头动画、无光点，阶段直接切换，反馈卡片照常出现。

## 6. 角色台词（短、克制）

“今天想先照料哪一朵？”（今日建议）、“你上次的问题，在这里。”（定位原消息）、“你上次的问题，都在这条小径上。”（历史）、“这次你没有用提示。”（独立变式验证后开花）。不使用打卡、连续天数等制造焦虑的提示。

## 7. 面板与信息层级

- 暖奶油色纸张 + 柔和阴影；减少边框与胶囊标签。
- 技术信息收进“查看详情”：每条回答的模型 / 演示说明、耗时、引用数量、消息编号；演示模式在顶部是一个小标签，点开显示说明。
- 演示标注、“预置”标注、错误提示与重试均保留。

## 8. 性能措施

DPR 上限 1.75（专注模式 1.25）；一个带阴影的主光；纹理最大 1024²；草丛与野花各一次实例化绘制；几何体与材质按参数缓存复用；粒子 9 个；远处星球低细节；入场灯光分级更新，避免每帧重渲染整个场景；无后期处理。WebGL 不可用或初始化失败时自动切换为静态绘本场景，所有功能通过普通界面可用。

## 9. 已知限制（如实说明）

- 3D 只在 SwiftShader 软件渲染下截图与测试，**没有在真实 GPU、真机手机上测帧率**。
- 没有景深与 Bloom 后期；“柔和”主要靠哑光材质、光晕精灵与阴影。
- 旅人没有骨骼动画；种子 / 嫩芽阶段四种花共用模型。
- 触屏没有悬停，标签只在选中时显示。
- 开场页与新手引导使用静态绘本场景（未加载 3D，以保证首屏速度）。
