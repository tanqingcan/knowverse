# 资料流水线与检索设计

## C2 资料处理（2026-11-11）

上传 → 大小/文件头校验 → 保存原文件和版本元数据 → 事务外提取 → 短事务写片段、状态与知识点候选。API 在读取文件为 Buffer 前检查 10 MB 限制，服务层也保留检查。数据库结构和前端接口沿用现有设计。

|类型|处理方式|定位|
|---|---|---|
|TXT|UTF-8，按空行分段；拒绝含 NUL 或 PDF/ZIP 头的伪装文本|非空文本块段号|
|Markdown|识别1–6级标题，标题无需用空行隔开；围栏代码中的标题符号保持正文|标题路径与段号，标题也占段号|
|文本PDF|按页提取，规范化部首字符，长页分块|原PDF页码|
|PPTX|按演示文稿顺序读取正文；根据每页关系文件解析演讲者备注；排除备注页码、页眉页脚占位符|原幻灯片页码，heading注明备注|
|Word/Excel|保留现有文件名、MIME、大小、SHA-256、版本和存储位置；检查OOXML ZIP及对应主部件存在，正文不提取|状态说明区分Word/Excel|

长片段上限700字符；优先在后半段的句子/换行边界切分，无法找到边界时硬切。相邻长片段最多重叠80字符；不跨页、段落或标题边界拼接。长度按JavaScript字符串计数，不是模型token。

## 状态约定

- `ready`：已有可引用文本。
- `needs_ocr`：PDF文字层过少或PPT没有可提取正文/备注；仅提示OCR，不执行OCR。
- `unsupported`：已保存元数据，类型不支持正文提取；有效Word/Excel属于此类。
- `failed`：文件损坏或Office包内容与扩展名不一致。
- 文件超限、空文件、明显伪装扩展名在上传入口拒绝，不创建成功版本。

旧资料版本和引用不重算。改进仅作用于后续上传，若要体验可上传为新资料或新版本。

## 验收与复现

`tests/unit/extract.test.ts` 覆盖真实PDF/扫描件、PPT备注关系映射、Word/Excel元数据、标题边界、代码围栏、无标点长段落、重叠完整性、伪造扩展名和大小限制。完整测试还包含旧回答引用版本保持不变的集成用例。

本轮实测：类型检查通过，17个测试文件、146个用例全部通过，其中C2新增9例。验证为提取函数与服务层测试，尚未在浏览器中逐项操作验收。

界面演示：

1. 在“资料”选择数据库学科，上传 `seed/materials/C2-含备注的连接查询课件.pptx`。打开内容片段，找到“星灯备注实验”，应标第1页且标题带“备注”。
2. 上传 `seed/materials/C2-标题与长段落示例.md`，查看多级标题路径与多个长段片段；相邻长片段有重叠。
3. 上传 `seed/materials/扫描版习题-示例.pdf`，应显示需要OCR。
4. 上传有效docx/xlsx，应显示仅元数据，状态详情注明正文未提取。
5. 文本文件改成.pdf后上传应被拒绝，超过10 MB的文件也应被拒绝。

## 局限

Office识别检查主部件，不是完整Office格式验证；XML读取沿用轻量正则，复杂命名空间/嵌入对象、图表、图片、公式不在本次保证范围内。扫描检测是启发式，不做逐页OCR。只保存元数据不代表Word/Excel正文已可检索。C4已增加词法重排、同页相邻片段的上下文合组及原文摘录校验；语义蕴含仍需审阅。
