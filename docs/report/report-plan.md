## 2. 章节内容

| 章节 | 负责人 | 主要内容 |
|---|---|---|
| 摘要 | **A** | 研究背景、问题、方法、主要结果与结论；系统主图 |
| 1 需求分析 | **C** | 学习场景、功能/非功能需求、需求—验收对应关系 |
| 2 概要设计 | **B** | 系统分层、模块边界与职责；引用系统主图 |
| 3 数据库设计 | **A** | 业务链与实体联系、Chen-ER、关系模式、候选键/函数依赖/规范化、约束与事务、索引与访问路径 |
| 4 核心业务详细设计 | **C** | 答疑与历史检索、私有资料与 RAG、记忆、练习与沙箱、成长与班级协作 |
| 5 系统实现与交互 | **B** | 技术栈与目录、关键流程、演示/真实模式；同一案例的组合截图与前端性能 |
| 6 系统测试与实验评测 | **D** | 测试策略、6.1—6.5 实验、结果与边界 |
| 7 部署与运行维护 | **B** | 环境、迁移、启动、配置与持久化、备份与回滚 |
| 8 大模型辅助设计与审查 | **D** | 模型辅助记录、采纳/修改/否决及依据 |
| 9 总结、局限与后续计划 | **D** | 完成度、局限、后续工作 |
| 附录 | **A、B、C、D** | 全库字段图、完整 EXPLAIN、SQL、截图与评测记录 |
