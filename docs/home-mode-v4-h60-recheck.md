## 三、复核执行方式（本轮起）

1. **每项必须在真实浏览器里用鼠标/键盘/触屏完成**，录屏或逐步截图保留；脚本只做辅助取证，不作为通过依据。
2. 记录「用户从花园开始的最少操作步数」，与要求对比。
3. 若某项依赖尚未修复的功能（如 H13 隐藏），先修功能再复核，不得先标通过。
4. 手机软键盘、中文 IME、真 GPU FPS 三项在本机无法构造时，**保留未验证**并写清原因。
