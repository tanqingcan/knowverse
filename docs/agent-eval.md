## 复现

保持数据库运行，在配置了模型的本机执行 `npm run eval:agent`。每次创建独立的禁用登录评测账号，只使用固定课程问题和该账号自身历史；不重置演示用户。账号与问答保留以便追溯，结果写入 `docs/test-evidence/agent-live.json`，再次运行会覆盖该结果文件。真实调用会产生 API 费用。

## 问题与修复

- 首轮记录保留于 `test-evidence/agent-live-before.json`。早期失败包括合法 JSON 内 SQL 代码块被误解析，以及概率题错误限定在数据库学科。修复解析器并校正评测条件后复测，因此首轮和最终结果不能当作纯算法效果对照。
- 每轮显式请求 JSON；结构非法时最多一次格式修复；不对 HTTP 失败无限重试。
- 模型工具请求执行前重新检查白名单，禁止调用仅限后端的写入工具。
- DeepSeek 使用非思考模式；当前没有实现思考内容的工具续接协议。

## 局限与后续

- 10 条是冒烟集；C4 仍需 50 条引用支持性评测。关键词检查可能误判，尤其不能替代语义审阅。
- C3 倒排检索、C5 自动记忆尚未在本次实现。
- 测试库需预先创建；本机已补建，自动创建测试库由 D2 负责。
- 提示注入拒绝仅覆盖这一个固定请求，不证明系统全面安全。
