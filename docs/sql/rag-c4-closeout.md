## 修复原则

- 没找到可用资料：提示“资料不足”。已找到资料、引用不合规：提示“引用校验未通过”。
- 只允许一次引用修复；输入资料和草稿均作为数据。明确要求扁平JSON对象、正文句末标记、对应编号的连续短摘录。
- 修复后的引用必须重新通过原来的摘录校验；不自动补标记，不允许改成general或删quote绕过。失败保留首次已验证引用。
- 不放宽数字、否定词、跨片段拼接或省略号；空白归一化只处理排版。
- 调用轨迹记录修复是否尝试/成功，额外调用用量累计。pending中断阈值按最多5次模型调用预算调整。
