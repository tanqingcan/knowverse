### H02 所有建筑可点选/移动/旋转/缩放/复制（无双轨）

- **要求**：原初始书屋/小屋、温室、观星台、棚子等全部可点选、移动、旋转、缩放、复制；不允许「原模型固定，新加的才能动」的双轨。
- **前置依赖**：H01 目录；`SPOTS` 固定渲染分支。

#### GitHub 候选对比与已读源码
- 复用 `docs/home-editor-references.md`：
  - **three.js `Editor.js`（MIT）**：`signals.objectSelected/objectAdded/sceneGraphChanged` 说明「建筑作为场景对象」统一进对象表，选择/新增只发信号。
  - **drei `TransformControls.tsx`（MIT）** L88-93：`dragging-changed → defaultControls.enabled = !value`，用于变换期间暂停相机。
  - **drei `PivotControls`（MIT）**：局部锚点 + `onDragStart/onDrag/onDragEnd`，对应本项目的球面 (x,z,rot,scale) 参数化。
- 结论：建筑统一为布局实例 + 复用现有 `OnCap`/拖动通道，不引入 gizmo。

#### 第一遍审查（主动构造失败）
1. **[高] 拖动建筑不移动**：编辑模式选中种子小棚后从 (420,200) 拖到 (520,270)，localStorage 中 seedshed 仍为 `{x:-0.15,z:-0.95}` → `moved: False`。疑似 `decorDrag` 起手/星球 `onPointerMove` 命中链路问题（后续修复方向：改从 `dragging` 标志 + 统一 pointer capture 处理）。
2. **[高] 木牌文字硬编码**：`DecorItem` 的 sign 分支写死 `text="晚星" sub="本命花"`（原渲染是 `props.signText/signSub`），换用户即错。
3. **[中] 热点尺寸不随缩放**：Hit 是 scale group 的兄弟，建筑放大后热点相对变小 → 已改为 `r*scale / h*scale`。
4. **[中] 复制的建筑标签锚点 key 冲突**：`register(hit.name)` 用 kind 作 key，复制同种建筑会覆盖锚点（H05 处理）。
5. **[中] 旧布局迁移只写本地草稿**：需用户保存一次才跨设备生效（已加提示「已按新版补入初始建筑（保存后生效）」）。
6. **[待验] 观测台/小池塘/长椅/路灯**：网格扫描只找到 6 个对象，其余可能在背面/边缘或遮挡；需旋转视角确认非渲染缺失。
