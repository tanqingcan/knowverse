### H21 点击槽位 → 半透明放置预览、单次/连续放置、Esc 取消、有效/无效反馈

- **要求**：点击槽位选择素材，出现半透明放置预览；单次/连续放置开关，Esc 取消，放置有效/无效反馈明确。
- **前置依赖**：H17（快捷栏）、H06（ghost 预览机制）。

#### GitHub 候选对比与已读源码
- 复用 `docs/home-editor-references.md`：**fernforge-arcade/minecraft-clone（无 license，仅交互）** 的「选中方块后出现半透明 ghost、点击落位」；**drei `TransformControls`（MIT）** 的 `dragging` 生命周期说明「预览态与应用态要分离」。
- 本项目实现：ghost 复用 H06 的 `placingPreview`（克隆材质降 0.55 透明度 + 底座 honey 环 + 命令式跟随指针），放置层用 `sphereGeo(3.12)` 捕获点击。

#### 第一遍实现
- 槽位点击 → `setPlacingKind(kind)` → `placingPreview` 出现半透明 ghost；`.hb-hint` 提示「把指针移到星球上，出现半透明预览后点击放置 · Esc 取消」。
- 新增 `continuous` 状态 + 快捷栏「连续」开关（`aria-pressed` + 高亮）；`onPlace` 在连续开启时保留 `placingKind`，否则放完退出并选中新实例。
- Esc 沿用 H18/H19 的层级：先关库 → 取消放置 → 取消选中 → 退出创造。

#### 第一遍审查（主动构造失败）
1. **[中] 放置成功没有任何反馈**：放完后只有总数变化，用户不知道放没放上（连续模式下尤其明显）。
2. **[中] 「无效」反馈是隐式的**：指针不在星球上时 ghost 直接隐藏、点击也不会放置，但没有红色/警告态，只能靠 hint 文案理解。
3. **[低] 连续开关不持久化**：属会话态（每次进入创造重置），需明确记录。

#### 第二遍实现（修复 #1）
- `onPlace` 成功后 `setLayoutMsg("已放置「玫瑰」（共 N 件）· 连续放置中")` → 显示在热栏消息条 `.hb-msg`（全局可见，不依赖素材库是否打开）。
