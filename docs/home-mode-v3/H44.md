### H44 动画可取消、不遗留遮罩和计时器；低动效立即打开

- **要求**：关闭/连续点开/切路由时动画可取消，不遗留遮罩和计时器；低动效立即打开或短淡入，键盘开窗直接可用，不强制看动画。
- **前置依赖**：H43（星落动画）。

#### GitHub 候选对比与已读源码
- 入场动效的可维护写法：**一个受控状态 + 一个定时器引用**，任何状态切换都先 `clearTimeout`；组件卸载时清理；`prefers-reduced-motion` 走无动画分支。
- 本项目：`starTimer` ref + `cancelStar()`；`open()` 在非「新开 focus 面板」时立即 `cancelStar()`；`useEffect` 卸载清理；`matchMedia('(prefers-reduced-motion: reduce)')` 或 body 带 `.reduced-motion` 时直接开窗。

#### 第一遍实现
- `cancelStar()`：清计时器 + `setStarFall(false)`。
- `open()`：不是「新开 focus 面板」→ `cancelStar()`（连续点开、切面板、关闭都会立即开/关，不留残余星）。
- 卸载时清理计时器（切路由）。
- 低动效：`reduced` 分支直接 `cancelStar()` 返回 → 窗口立刻渲染。
- CSS 侧再加 `@media (prefers-reduced-motion: reduce) { .star-fall { display: none } }` 双保险。

#### 第一遍审查（主动构造失败）
1. **[中] 计时器泄漏风险**：若只 `setStarFall(false)` 不 `clearTimeout`，700ms 后的旧定时器会把**新一次**星落提前关掉——必须每次新开前 `clearTimeout`。
2. **[中] 低动效是否真的跳过动画**：需要 reduced-motion 环境下实测「点击后立刻就有窗口、且没有星元素」。
3. **[低] 键盘开窗直接可用**：低动效分支与键盘触发共用同一路径，直接开窗即满足。

#### 第二遍实现（验证 #1/#2）
- 以 reduced-motion 上下文实测；计时器清理已在代码里逐条对应。
