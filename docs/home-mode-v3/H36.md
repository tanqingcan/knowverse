### H36 工作台屏蔽场景快捷键、Esc 层级明确、焦点约束与归还

- **要求**：工作台屏蔽场景编辑快捷键；Esc 取消预览/返回层级明确，焦点约束与归还完整。
- **前置依赖**：H28（工作台）。

#### GitHub 候选对比与已读源码
- **three.js `Editor.js`（MIT）**：模态面板打开时快捷键作用域切到面板（`window.addEventListener` 里按当前面板判断）。
- **drei/React 惯例**：对话框需要 focus trap + Esc 关闭 + 关闭后焦点归还——本项目用**捕获阶段**监听 + Tab 循环实现（不引入第三方 dialog 库）。

#### 第一遍实现
- 工作台内：`window.addEventListener("keydown", onKey, true)`（捕获阶段）——
  - `Escape` → `stopPropagation()` + 取消并返回；
  - `Tab / Shift+Tab` → 在 `.diy-card` 内的可聚焦元素间循环（首尾回绕）；
  - 打开时把焦点移到第一个可聚焦元素，卸载时 `prev?.focus?.()` 归还。
- 场景快捷键：`SpaceApp` 三处 keydown（Ctrl+D 复制、1–9 切槽/E 开库、Esc 层级）都加 `if (diyTarget) return;` 守卫。

#### 第一遍审查（主动构造失败）
1. **[高] 快捷键屏蔽完全不生效**：实测工作台打开时按 `3` **槽位被切换**、按 `E` **打开了素材库**。
   **根因**：三处 keydown 的 `useEffect` 依赖数组里**没有 `diyTarget`**，闭包里的 `diyTarget` 永远是首帧的 `null` → 守卫永远为假。
2. **[中] Esc 关闭工作台后不应退出创造模式**：需确认层级（工作台 → 库 → 放置 → 选中 → 退出）不被跳过。
3. **[低] 焦点归还**：关闭后应回到触发 DIY 的元素（选中操作条里的 DIY 按钮），实测未逐项核对。

#### 第二遍实现（修复 #1）
- 三处 effect 依赖数组补 `diyTarget`：`[creativeOpen, selectedDecorId, diyTarget]`、`[creativeOpen, hotbar, diyTarget]`、`[creativeOpen, placingKind, selectedDecorId, libOpen, diyTarget]`。
- 修改文件：`src/components/space/SpaceApp.tsx`、`src/components/space/DiyWorkbench.tsx`。

#### 复审（全部通过）
- `.dsh-tools/h35-36.py`：
  - **工作台打开时焦点在 `.diy-card` 内**（`contains(activeElement) = True`）✓；
  - 按 `Digit3` / `KeyE` → **槽位不变（True）、素材库未打开（False）** ✓（屏蔽生效）；
  - 按 `Escape` → 工作台关闭且**仍在创造模式**（hotbar 仍在）✓ 层级正确；
  - 无 pageerror；`tsc` 0。
- **状态**：**双轮通过**（#3 焦点归还为已记录项）
