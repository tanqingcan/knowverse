- **要求**：手机预览和属性区有合理布局，键盘/色板不遮应用按钮。
- **前置依赖**：H28（工作台）、H24（触摸目标基线）。

#### GitHub 候选对比与已读源码
- **KolyaVol threejs-editor（MIT）**：编辑器面板在窄屏改为纵向堆叠（预览上、属性下）；本项目同策略：`@media (max-width:760px)` 下 `.diy-body` 变 `flex-direction: column`。
- 触控目标基线：H24 已确立「≥44 CSS px」，本轮把该基线套到工作台全部控件。

#### 第一遍实现
- 移动端 CSS：预览固定 210px 高、属性区 `max-height: 42vh` 可滚、`.diy-foot` 用 `position: sticky; bottom: 0` + 不透明底，保证应用按钮始终可见。

#### 第一遍审查（主动构造失败）
1. **[高] 触摸目标普遍不足**：390×844 实测 `.diy-card` 内有 **16 个控件高度 <44px**（取消 31px、部位按钮 36px、预设 34px）——手指难点，属真实可用性缺陷。
2. **[待验] 应用按钮是否被色板/面板遮住**：需实测按钮矩形是否完整落在视口内。
3. **[未验证] 软键盘遮挡**：真机软键盘弹起会压缩视口，桌面 Chromium 模拟无法证明。

#### 第二遍实现（修复 #1）
- 移动端补：`.diy-card button/select/input[type=color] { min-height: 44px }`、`.diy-part{padding:8px 12px}`、`.diy-preset{align-items:center}`、`.diy-foot{position:sticky;bottom:0}`。
