### H46 半透明背景局部虚化 + 中性色层；正文对比度 ≥4.5:1；不整颗星球虚化

- **要求**：半透明背景使用当前实景局部虚化加中性色层，文字所在区域保持对比度；正文对比度目标至少 4.5:1，不能因透明而不可读。不得把整颗星球高强度虚化来回避遮挡目标。
- **前置依赖**：H39–H42（窗口尺寸与内容）。

#### GitHub 候选对比与已读源码
- 玻璃拟态的通用做法：**只在浮窗自身做 `backdrop-filter`**（局部虚化），而不是给整个场景加模糊——后者既昂贵又会让人看不清「窗外」发生了什么。
- 本项目：`.focus` 自身 `background: rgba(255,247,232,0.9)` + `backdrop-filter: blur(18px) saturate(1.08)`；`.world-wrap` **没有任何 filter**。

#### 第一遍实现
- 沿用局部毛玻璃；对比度用 WCAG 公式实测（正文色 vs 背景合成色，把「窗外很暗」当作最坏情况）。

#### 第一遍审查（主动构造失败）
1. **[高] 次要文字在最坏背景下不达标**：正文 `#3F3657` 10.51:1 没问题，但 `.muted` 原文 `[111,103,137]` 在「窗外全黑」合成背景下只有 **3.59:1**、中灰背景 4.18:1 —— 低于 4.5:1。
2. **[中] 半透明底偏薄**：`alpha 0.86` 时窗外暗色透上来更多。
3. **[待验] 是否对整颗星球虚化**：需确认 `.world-wrap` 无 filter。

#### 第二遍实现（修复 #1/#2）
- `.focus` 背景 alpha **0.86 → 0.9**；
- 窗内次要文字（`.muted/.stage-label/.small`）改为 `#5A5375`。
- 修改文件：`src/app/globals.css`。
