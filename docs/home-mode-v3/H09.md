### H09 门口/标签/热点/停靠点/道路随实例变换

- **要求**：建筑门口、标签、碰撞、热点、星灯停靠和角色交互点随实例变换更新；道路至少随端点正确重建或显式成为可编辑独立对象，不能留下旧地表入口印迹。
- **前置依赖**：H02（实例化）、H08（热点分流）。

#### GitHub 候选对比与已读源码
- 复用 `docs/home-editor-references.md`：
  - **three.js `Editor.js`（MIT）**：对象移动后 `sceneGraphChanged` 触发，**附属物不是独立更新的**——它们要么是子对象、要么每帧从父对象推导。本项目采用后者：`homePoses()` 每次从布局推导锚点。
  - **drei `PivotControls`（MIT）** 的 `anchor` 概念：附属点应表达为**父对象的局部偏移**（本项目用 `doorOf(pose, defSpot, doorDef)` 把门口偏移按 yaw 旋转），而不是写死世界坐标。

#### 第一遍实现
- 新增 `src/lib/home/home-layout.ts`：
  - `homePoses(decor)`：从布局实例推导 `cottage/greenhouse/observatory/seedshed/arch/pond/bench/lamp/sign/lampSpot` 的 `{x,z,yaw}`；星灯停靠点按书房朝向旋转后的相对偏移跟随书房。
  - `doorOf(pose, defSpot, doorDef)`：把「门口相对建筑的偏移」按当前 yaw 旋转，得到当前门口位置。
- `GardenWorld`：
  - `poses = useMemo(homePoses(props.decor), [decor])`；`paintTerrain(beds, poses)`；
  - `MemoryPath` 接收 `poses`，四条小路按当前端点重建：回忆小径→书房门口、温室小路→温室门口、星径→温室门口→观测台、种子小径→温室门口→种子棚。
- `terrain.ts`：`paintTerrain(beds, poses?)`，四座建筑的地表印迹改为按 poses 位置绘制。
- **第一遍证据**（`.dsh-tools/h09-poses.py`）：编辑模式拖动书房 `(0.92,-0.92) → (-0.35,-0.51)`，画布前后截图 `h09-before.png` / `h09-after.png`；无 pageerror。

#### 第一遍审查（主动构造失败）
1. **[高] 地表重绘泄漏纹理**：poses 变化触发 `paintTerrain` 重绘 CanvasTexture，旧纹理没有 `dispose()` → 实测一次拖动后 `textures 12→20`（拖 10 次就 +80，属于 H55 要抓的单调累积）。
2. **[中] 拖动过程中每次 tick 都重绘地表**：画布重绘 + 纹理上传开销大，低端设备可能掉帧（记录给 H55）。
3. **[中] 角色（小旅人）路径仍用固定 `MEMORY_PATH`**：星灯停靠点已跟随书房，但旅人路线没跟着重建（回链 H09 遗留 / H55 观感）。
4. **[边界] 建筑被删除后**：`homePoses` 找不到实例 → 回落到 `SPOTS` 默认位（印迹会回到原位）——删除建筑是 H13 的语义，届时需一并处理「印迹是否消失」。

#### 第二遍实现（修复 #1）
- `GardenWorld` 增加 `useEffect(() => () => terrain?.dispose?.(), [terrain])`：poses 变化时释放上一张地表纹理。
- 修改文件：`src/components/world/GardenWorld.tsx`。
- **修复后复测**（`.dsh-tools/h09b.py`）：选中建筑后连按 6 次旋转（每次都触发 poses 变化 + 地表重绘）→ `textures 12 → 12`，**delta = 0**（不再增长）；`tsc` 0；无 pageerror。
