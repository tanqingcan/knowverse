- **要求**：检查 /space、/visit、/dev/garden 等真实路径和静态降级，无新增 pageerror、404 模型、重复监听、NaN、无限保存循环。
- **前置依赖**：全部前序项。

#### GitHub 候选对比与已读源码
- 路由级回归的正规做法：**按真实路由逐个打开**、监听 `pageerror`/`requestfailed`/4xx-5xx，并对可量化风险（数值 NaN、监听器叠加、保存循环）做**时间维度**观测（静置 N 秒看请求数）。
- 本项目已有探针：`__gardenYaw`/`__decorMoves`/`__camMoves`（相机与拖拽健康）。

#### 第一遍实现（三条路径 + 静置观测）
- `.dsh-tools/h54-routes.py`：分别打开 `/space`、`/visit?u=<demoId>`、`/dev/garden`，收集 pageerror、失败请求、≥400 响应、DOM 中的 NaN/Infinity。
- `.dsh-tools/h54-space.py`：登录后进 `/space`，**闲置 12 秒 + 创造模式闲置 12 秒**统计 PUT 次数；校验全部装饰数值有限；滚轮切槽步进。

#### 第一遍审查（主动构造失败）
1. **[中] 首轮 `/space` 未登录就测**：拿到的是落地页（`canvases=0`、`hasWorld=false`），根本没用例价值——必须带 demo 会话重测。
2. **[中] 一个 dynamic chunk 请求 `net::ERR_ABORTED`**：`StaticGarden` 组件 chunk 被浏览器**主动中止**（未使用时的预取取消），不是 404、也没有 pageerror、页面最终 canvas 正常。
3. **[待验] 是否存在保存循环**：需要时间维度观测，不能只测一次。

#### 第二遍实现（修复 #1、记录 #2）
- 带 demo 会话重测 `/space`：`canvases=1 / hasWorld=true / NaN=0`；静置与创造模式静置 **PUT 次数均为 0**（**无无限保存循环**）；装饰数值异常 **0**。
- #2 如实记录：这是预取中止，非资源 404；生产构建下该 chunk 走静态资源，未见此现象。
