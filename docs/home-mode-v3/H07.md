### H07 克隆保留外观尺寸、材质独立

- **要求**：克隆保留允许的外观与尺寸，材质独立或正确实例化；修改复制品颜色不会连带原件。知识植物复制为装饰副本，不克隆学习记录。
- **前置依赖**：H06（复制预览确认）、H01（`colorParts` 登记）。

#### GitHub 候选对比与已读源码
- 复用 `docs/home-editor-references.md`：
  - **three.js `Editor.js`（MIT）**：`Material.clone()` 与 `MaterialPanel` 的按对象赋材质——编辑器里改材质必须落到**单个 mesh**，不能改共享材质实例。
  - **drei `TransformControls`（MIT）** 无关；另查本项目 `geo.ts`：`matte()` 用 `Map` **按颜色字符串全局缓存材质**——这就是「串色」的根源，必须克隆。

#### 第一遍实现
- `DecorItem` 新增 `Tinted`：程序化模型若有 `color`，**遍历 mesh 克隆材质**再改色，卸载时 `dispose()`；GLB 路径原本已按实例 `clone()`（`Model.tsx` L14-19）。
- `CreativePalette` 属性面板加「颜色」色板 + 「默认」恢复按钮；`selected.color` / `onUpdate({color})` 类型补齐。
- **第一遍证据**（`.dsh-tools/h07-color.py`）：
  - 放一朵玫瑰 → 复制（预览确认）→ 4 朵，新实例位置 `(0.7,0.22)`；
  - 把**复制品**颜色改成 `#d24b4b` → `copy.color=#d24b4b`，**`orig.color` 仍为 None（orig unchanged: True）**；
  - id 全唯一；vision 复核截图：**一朵明显红色、其余保持原粉/杏色**（不串色）。

#### 第一遍审查（主动构造失败）
1. **[中] 切换阶段后新网格丢色**：`Tinted` 的 effect 只在 `tint` 变化时跑；玫瑰切 `stage` 会重建网格，新网格用的是 `matte()` 缓存材质 → 颜色丢失。复现：改色后再切阶段。
2. **[中] `dispose()` 与缓存材质的关系**：克隆材质 dispose 是安全的（缓存原件不受影响），但如果将来把克隆材质写回缓存会误删全局材质——记录为禁忌。
3. **[低] 知识植物语义**：装饰玫瑰复制只复制布局数据（`kind/color/stage`），不涉及 `beds/plantMap` 学习记录；但**同一 kind 既可能是知识植物也可能是装饰花**，当前靠数据来源区分，缺少显式标记。
4. **[边界] 「默认」恢复**：`onUpdate({color: undefined})` 后 JSON 序列化丢弃该键 → Tinted 不再挂载，回到缓存材质，已验证可用。

#### 第二遍实现（修复 #1）
- `Tinted` 增加 `key={`${kind}:${stage}:${tint}`}` 强制重挂载：切阶段/改色都会重新克隆材质，新网格不会回退到缓存材质。
