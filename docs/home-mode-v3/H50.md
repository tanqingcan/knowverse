#### 第一遍审查（主动构造失败）
1. **[中] 录屏是否真的录到星落**：录制起点在 `/space` 加载完之后，覆盖点击与 700ms 动画；但 Playwright 录屏为固定帧率，可能漏掉极短帧——需要文件存在 + 大小合理作为证据，不能只看「配置了录屏」。
2. **[低] 低动效截图与默认截图尺寸相同**：这是**预期**（低动效只是跳过动画，不改变窗口尺寸），需要在对照里写明，避免看起来像重复截图。
3. **[待验] 面积对照是否用同一口径**：A0 是「旧 `.focus` 外框」，新窗也是「`.focus` 外框」，口径一致。

#### 第二遍实现（补齐 #1/#3 证据）
