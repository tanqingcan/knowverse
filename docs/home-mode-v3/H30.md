### H30 颜色即时预览、预设协调配色、自定义、单部位恢复、显示当前部位

- **要求**：颜色即时预览，支持预设协调配色、自定义颜色和单部位恢复；显示当前改动部位，符合绘本粗糙度和暖光，不强制改成金属。
- **前置依赖**：H28（工作台）、H29（分区材质）。

#### GitHub 候选对比与已读源码
- **KolyaVol threejs-editor（MIT）**：材质库有「预设配色」与单材质编辑两类入口；本项目据此把「预设」做成整对象协调套色、把「自定义」限制在**当前选中部位**，避免一次改全部。
- **three.js `Editor.js`（MIT）**：颜色修改即时作用在材质上（无需提交），提交只在命令执行时——对应「预览即时、应用才落库」。

#### 第一遍实现
- 工作台内：自定义取色 `onChange` 直接改本地 `parts` → 预览 Canvas 立刻重渲染（**即时预览**）；6 套暖光协调预设（每套按部位顺序套色）；「恢复本部位默认色」只重置当前部位；顶部常显「当前部位：花瓣」。
- 材质是 `MeshStandardMaterial` + `roughness≈0.8–0.95`、`metalness: 0`，保持绘本粗糙暖光，不出现金属感。

#### 第一遍审查（主动构造失败）
1. **[中] 预设套色顺序依赖部位数量**：4 色预设套到 3 部位的花时最后一色闲置；不是按语义（屋顶→墙面→门窗→饰边）绑定。属于「协调"感」够用但不够精确。
2. **[低] 自定义取色在部分浏览器需要点击确认**（原生 `input[type=color]` 行为），非纯拖拽。
3. **[待验] 「即时预览」只有色块证据**：需确认画布里的模型也真的变了（H29 已用 vision 验过屋顶/花茎，本轮再验一次色块与模型同步）。

#### 第二遍实现（验证 #3 + 记录 #1/#2）
- 本轮以「色块 + 模型」双证据验收即时预览；#1/#2 如实记录不修。
