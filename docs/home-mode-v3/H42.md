### H42 会话历史默认折叠；主体只显示当前内容；输入框固定窗内

- **要求**：会话历史默认折叠为标题/选择器，示例问题折叠或短列表；主体只显示当前内容、紧凑输入和发送。正文内部滚动，输入框固定于窗口内，引用/重试/错误态仍可用。
- **前置依赖**：H39/H41。

#### GitHub 候选对比与已读源码
- 对话框通用结构：**头部（标题/选择器）+ 可滚动主体 + 固定底部输入**。本项目原本把「会话列表」默认展开塞在主体顶部（实测 478×98，占掉小窗 1/3），这正是审核指出的「会话列表默认展开并占较大区域」。

#### 第一遍实现
- `ChatPanel`：`showList` 初值从 `!panel.conversationId` 改为 **`false`**；无会话时也不自动展开列表（`setShowList(false)`）。
- 会话历史仍在，通过头部「会话列表 · N」按钮展开（`aria-expanded`）。
- 输入框（`.composer`）在 flex 列的末尾，`.msgs` 为 `flex:1; min-height:0; overflow-y:auto`，因此**正文内部滚动、输入框固定在窗内底部**。
- 头部内边距/对话栏内边距按小窗重排（不再按 880px 居中留白）。

#### 第一遍审查（主动构造失败）
1. **[中] 折叠后历史是否还能用**：需要验证展开后列表仍可点、可切换会话。
2. **[中] 输入框是否真的固定在窗内底部**：需要测 `.composer` 底边是否等于窗口底边。
3. **[待验] 引用/重试/错误态**在 480×380 下是否仍可见（本轮未逐态构造）。

#### 第二遍实现（验证 #1/#2）
- 复审断言：`.composer` 底边 == 窗口底边、`.msgs` 独立滚动、展开历史后列表高度 >0。
