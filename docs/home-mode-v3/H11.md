### H11 数值/按钮精调、轴义清楚、缩放基点贴地、变换期间相机暂停

- **要求**：允许数值/按钮精调，方向轴含义清楚，缩放基点贴地；变换期间相机暂停，释放后恢复。
- **前置依赖**：H02/H10（拖动链路）。

#### GitHub 候选对比与已读源码
- **drei `TransformControls.tsx`（MIT）L88-93**：`controls.addEventListener('dragging-changed', e => defaultControls.enabled = !e.value)`——变换开始禁用相机、结束恢复。本项目对应：`.world` 的 `pointermove` 在 `decorDrag.current` 非空时直接 return；`pointerup` 清空 `decorDrag`。
- **three.js `Editor.js`（MIT）**：数值输入走对象 position 增量命令，对应本项目滑杆 `onUpdate({x,z,rot,scale})`。

#### 第一遍实现
- `CreativePalette` 新增两个位置滑杆：**位置 X（左右）** / **位置 Z（前后）**（±4，step 0.05，两位小数），与比例/旋转/长/宽共 6 个滑杆。
- 缩放 `<group scale={d.scale}>` 挂在 `OnCap` 原点（球面表面点）→ 缩放基点贴地。

#### 第一遍审查（主动构造失败）
1. **[中] 对象拖动期间相机 yaw 漂移 +0.0245 rad（1.4°）**——最初怀疑 pointermove 泄漏。
2. **[低] 轴义**：X/Z 是球冠平面坐标，非世界东西南北；用「左右/前后」标注缓解。
3. **[待验] 缩放基点**：缺放大后底座仍贴地的视觉证据。

#### 第二遍实现（诊断 + 修复）
- **加探针定位**（不猜）：在 `.world` pointermove 的两个分支分别计数 `window.__decorMoves` 与 `window.__camMoves`。
- **探针结论**：`decorMoves=7, camMoves=0` —— 指针**没有**移动相机，但 yaw 仍漂移 → 真凶是**空闲慢转（idle auto-rotate）**：`decorDrag` 分支没有刷新 `lastAct`，超过 3s 后慢转在拖动中接管镜头。
- **修复**：`decorDrag` 分支里 `lastAct.current = now`（拖动即视为活动）。
- 修改文件：`src/components/world/GardenWorld.tsx`。

#### 复审（全部通过）
- 对象拖动：`decorMoves=7, camMoves=0`，**yaw 完全不变**（`0.25658 → 0.25658`）✓
- 释放后拖画布：`camMoves=7`，**相机恢复旋转**（yaw 明显变化）✓
- 缩放：滑杆 ×20 次 → `max scale = 2.00`，截图 `h11-scale2x.png`，vision 确认「底座仍贴着球面」✓
- `tsc` 0；无 pageerror。

- **状态**：**双轮通过**
