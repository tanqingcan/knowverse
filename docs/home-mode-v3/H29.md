### H29 模型按部位独立材质（花：花瓣/花心/叶片/茎；房屋：屋顶/墙面/门窗/饰边）

- **要求**：花至少区分花瓣/花心/叶片与茎；房屋至少区分屋顶/墙面/门窗饰边。模型没有独立材质槽时先调整建模结构，不能整栋房子统一染一色冒充 DIY。
- **前置依赖**：H28（工作台）。

#### GitHub 候选对比与已读源码
- **three.js `Editor.js`（MIT）**：材质是按 **mesh** 赋的，编辑器改材质只影响选中对象的选中 mesh——所以「分区」必须在建模层就把不同部位拆成不同 mesh/材质，UI 层没法凭空分。
- 本项目排查结论：`geo.ts` 的 `matte(color)` 按颜色全局缓存（同色跨部位共用）；花用的是 `vcol("petal")`/`vcol("leaf")`（顶点色共享材质）；房屋用的是 `matte(C.roof/C.plaster/C.window/C.wood)` —— **颜色是烘焙在材质里的，没有「部位」这一层**。

#### 第一遍实现
- 新增 **`PartTint`** 组件（`DecorItem.tsx`）：
  - 遍历模型网格，按 **`userData.part` 标记** 或 **材质身份**（`vcol("petal")` / `vcol("leaf")`）判定部位；
  - 命中部位则**克隆材质**改色、卸载时 `dispose`（不复用全局缓存材质，避免 H07 的串色风险）；
  - `DecorItem` 新增 `parts` 参数并包裹；`key` 带 kind/stage/parts，切阶段或改色都重新克隆。
- **房屋建模调整**（`Props3D.tsx` 的 Cottage）：给墙、三片屋顶、圆窗、木饰边/门共 **7 个网格**打上 `userData={{ part: "wall"|"roof"|"window"|"trim" }}`。
- 数据链路：`GardenWorld` 的 `<DecorItem … parts={d.parts} />`；DIY 预览同样传 `parts`。

#### 第一遍审查（主动构造失败）
1. **[高] 花的「花心 / 茎」仍与其它部位共用材质**：`foliageGeo` 把叶与茎的顶点色合并到**同一个 mesh**、材质都是 `vcol("leaf")`；花心多数也烘在花瓣几何里。→ **工作台里「花心」「茎」两个分区目前是空操作**（点了没变化），只有「花瓣」「叶片」真正生效。
2. **[中] 顶点色材质是「相乘」不是「替换」**：花瓣/叶片克隆后设 `material.color`，最终色 = 顶点色 × 所选色，不等于所选色本身（属于 tint 语义，需如实说明）。
3. **[中] 只改了 Cottage 一个房屋**：温室/观测台/种子棚的网格还没打部位标记（工作台能显示分区但模型不响应）。
