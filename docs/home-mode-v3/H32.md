### H32 「仅当前对象」与「保存为我的素材变体」

- **要求**：支持「仅当前对象」与明确的「保存为我的素材变体」；变体新增放置复用配色，不隐式修改同类全部对象。
- **前置依赖**：H28/H31（工作台与应用路径）。

#### GitHub 候选对比与已读源码
- **KolyaVol threejs-editor（MIT）**：材质库允许把一套材质另存复用，但**不会回写**到场景里已有的同类对象；本项目据此把变体做成「个人配色预设」，只作用于**新放置**。
- **three.js `Editor.js`（MIT）**：`SetMaterialCommand` 只作用选中对象——「仅当前对象」语义与之一致。

#### 第一遍实现
- 新增 `src/lib/home/variants.ts`：按 kind 存 `{ [partKey]: '#rrggbb' }`（只接受 `#rrggbb`，坏数据丢弃），localStorage 键 `kv-diy-variants`。
- 工作台底部新增「**保存为素材变体**」按钮（与应用并列），文案与 title 明确「新放置同类素材时默认复用」。
- 放置路径：`onPlace` 在 `place()` 时带 `parts: variantOf(kind)` —— **只影响这个新对象**；已有同类对象不动。
- 「仅当前对象」= 原有「应用」按钮（`decorStore.update(id,{parts})`）。

#### 第一遍审查（主动构造失败）
1. **[中] 变体只能有一份/每类**：同 kind 再保存会覆盖旧变体（没有变体列表/命名）。属简化，记录。
2. **[中] 变体复用没有界面提示**：新放置带上了变体色，但用户不知道自己用了变体；只有一句保存成功提示。
3. **[低] 变体不影响「由模板/旧布局加载」的对象**：加载路径不读变体，符合「不隐式改同类」。
