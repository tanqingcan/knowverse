### H40 默认居中、星球窗外可见、明确的放大/专注模式、手机优先可读

- **要求**：默认居中，星球仍在窗外清楚可见；提供明确放大/专注模式，长代码或练习可由用户主动展开，默认不自动变成大窗。手机优先可读与操作，不强制套桌面面积比例。
- **前置依赖**：H39（窗口尺寸）、H41/H42（内容重构）。

#### GitHub 候选对比与已读源码
- 编辑器/浮层的通用模式：默认小窗 + 显式「放大/专注」切换（不自动变大）；移动端改为底部抽屉/近全宽。
- 本项目：默认居中浮窗；新增 `.focus-zoom` 按钮切换 `is-large`；移动端媒体查询改为底部 sheet（`left/right:0; bottom: safe-area`）。

#### 第一遍实现
- `focusLarge` 状态 → `main.className` 加 `is-large`；`.focus.is-large { width: min(880px, 100vw-48px); height: min(620px, 100vh-140px) }`。
- 头部按钮「放大 / 收起」（`aria-pressed`），关闭窗口时复位 `focusLarge`。
- 移动端：`.focus.is-large` 覆盖为近全屏；普通 `.focus` 为底部 sheet（`min(72dvh, …)`）。

#### 第一遍审查（主动构造失败）
1. **[高] 手机端学习窗会错位**：H39 给 `.focus` 加了 `transform: translate(-50%,-50%)` 居中，但移动端媒体查询只改了 `left/right/top/bottom`，**没重置 transform** → 手机上窗口会被再平移半屏。
2. **[低] 默认窗口有 10px 垂直偏移**：实测默认窗 `y=270`，而理论居中应为 `260`——来自入场动画 `kv-rise-c` 的 `+10px` 起始态；视觉可忽略但确实不精确。
3. **[待验] 放大模式是否会遮挡星球**：放大是用户主动行为，允许遮挡；需记录放大后的尺寸。

#### 第二遍实现（修复 #1）
- 移动端 `.focus` 补 `transform: none; width: auto;`，并把入场动画名换成 `kv-rise`（避免 `translate` 覆盖底部定位）。
- 修改文件：`src/app/globals.css`、`src/components/space/SpaceApp.tsx`。
