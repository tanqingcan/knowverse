### H05 选中建筑出现轮廓、名称与紧凑操作条

- **要求**：点击初始建筑后出现选中轮廓、名称和紧凑操作条；无须先从素材库重新添加才能操作。
- **前置依赖**：H02（建筑实例化 + 选中链路）。

#### GitHub 候选对比与已读源码
- 复用 `docs/home-editor-references.md`：
  - **three.js `Editor.js`（MIT）**：`signals.objectSelected` 触发 `objectSelected` 回调后由各面板订阅；选中状态与「显示什么」解耦——本项目用 `selectedDecorId` + 投影跟随的 DOM 条实现，不重建侧栏。
  - **KolyaVol threejs-editor（MIT）**：属性面板是**独立浮层**而不是常驻大侧栏——本项目据此把高频操作（名称/复制/删除）放进跟随对象的紧凑条。
- 未采用：不做 drei 的 HTML 注释（`Html`/`Billboard`），因为本项目已有 `LabelTracker` 的 DOM 投影方案（零 React 重渲染）。

#### 第一遍实现
- `GardenWorld`：
  - 每个装饰/建筑实例注册锚点 `decor:<id>`（高度按建筑/小件区分）；
  - 复用 `LabelTracker`（每帧投影、直接写 DOM transform、不触发 React 渲染）驱动新元素 `selEl`；
  - 新增 `.world-selbar`：名称 + 缩放倍率 + 「复制」「删除」，`role="group"` + `aria-label`。
- `WorldProps` 增 `onDecorDuplicate/onDecorRemove`；`SpaceApp` 传入（复制后选中新实例）。
- `globals.css`：`.world-selbar` / `.selbar-btn` 样式（哑光奶油底、圆角、≥30px 点击高）。
- **第一遍证据**（`.dsh-tools/h05-selbar3.py`）：编辑模式选中后 `.world-selbar` 出现、文本为对象名、2 个按钮；JS 点击「复制」→ 总数 **14→15**，再点「删除」→ **15→14**；无 pageerror。

#### 第一遍审查（主动构造失败）
1. **[中] 操作条会落在左侧素材栏下面**：投影 x 未夹取，实测一次 `box.x=133`（素材栏宽 264px），按钮被面板遮住点不到（Playwright 点击超时就是这个原因）。
2. **[中] Playwright 直接 click 超时**：操作条每帧被写 transform，自动化工具的「稳定性」检查可能一直不满足；真实用户可点（`getBoundingClientRect` 正常）。已改用 JS click 验证处理函数。
3. **[低] 选中轮廓仍只是底座光圈**：没有真正的描边（outline）效果，视觉上偏弱。
4. **[边界] 删除后选中状态**：删除后 `selEl` 应立即隐藏（`selItem` 变 undefined → 组件卸载），已验证不残留。

#### 第二遍实现（修复 #1）
- `LabelTracker` 增加 `minX` 参数：操作条投影 x 夹到 `292px`（素材栏右侧外），避免被面板遮挡。
- 修改文件：`src/components/world/GardenWorld.tsx`。
- **修复后复测**：`h05-selbar3.py` 仍通过；`tsc` 0；单测 42/42；无 pageerror。

#### 复审
