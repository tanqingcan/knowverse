### H20 槽位配置：放入槽位、空槽/重复/替换规则、个人配置可保存

- **要求**：支持拖入槽位或明确的「放入槽位」按钮；空槽、重复素材、替换槽位规则清楚。快捷栏个人配置可保存，不能把场景对象 ID 当素材 ID。
- **前置依赖**：H17/H19。

#### GitHub 候选对比与已读源码
- 复用 `docs/home-editor-references.md`：**fernforge-arcade/minecraft-clone（无 license，仅交互）** 的「物品栏放入快捷栏」交互（拖拽或点选写入）。
- 与 minecraft-clone 的差异：本项目不做拖拽（触屏与球面画布冲突），改用**明确的「放入槽位」按钮**——目标要求是「拖入 **或** 按钮」，按钮路径合规。
- 数据约束：槽位里存的是**素材 kind**（`rose`/`road`…），不是场景实例 ID（`home-cottage`/`d-xxx`）。

#### 第一遍实现
- `hotbar` 类型改为 `(DecorKind | null)[]`（允许空槽）；`activeSlot` 记录当前槽。
- 素材库头部新增「放入第 N 槽」按钮（切换为「选材放入第 N 槽…」模式），此时点素材 = 写入当前槽（**覆盖**已有素材），并关闭库回到星球。
- 持久化：`useEffect` 监听 `hotbar` → 写 `localStorage[kv-hotbar]`；加载时校验 9 项且每项为 `null` 或合法 kind。
