### H22 选中对象显示移动/旋转/缩放/复制/DIY/删除按钮

- **要求**：选中场景对象时显示移动/旋转/缩放/复制/DIY/隐藏或删除按钮，未选中时收起。不会因为选中对象而重新显示原大侧栏。
- **前置依赖**：H05（紧凑操作条）、H12（历史）、H17（快捷栏）。

#### GitHub 候选对比与已读源码
- **KolyaVol threejs-editor（MIT）**：属性面板是**可收起的浮层**，编辑动作（移动/旋转/缩放）与属性编辑分离；本项目把「动作按钮」放在跟随对象的紧凑条上，把「数值精调」放进一个 232px 的小浮层。
- **three.js `Editor.js`（MIT）**：`transformModeChanged` 信号切换 transform 模式——对应本项目「移动/旋转/缩放」三个维度切换浮层内容。
- 未采用：不引入 drei gizmo（球面语义不兼容，见 H10）。

#### 第一遍实现
- `.world-selbar` 从 2 个按钮扩到 **6 个**：移动 / 旋转 / 缩放 / 复制 / DIY / 删除。
  - 移动/旋转/缩放 → 打开 `.sel-edit` **紧凑属性浮层**（右下 232px），只显示该维度的滑杆（左右/前后、角度、比例），点「收起」或换维度即更新内容。
  - 复制 → `onDecorDuplicate`（H06 的预览复制）；删除 → `onDecorRemove`；DIY → `onDecorDiy`（当前为占位 toast，工作台在 H28–H38）。
- `WorldProps` 新增 `onDecorUpdate`（写入 x/z/rot/scale，走 `decorStore.update` → 历史栈）与 `onDecorDiy`。
- 选中失效时 `selEdit` 自动关闭（`useEffect`）。

#### 第一遍审查（主动构造失败）
1. **[中] DIY 目前只是占位**：按钮存在但点后只弹「DIY 工作台将在下一组任务提供（H28–H38）」——属于如实占位，不能算 DIY 已完成。
2. **[中] 操作条变宽后的右侧溢出**：6 按钮 + 名称 + 倍率使 `.world-selbar` 宽约 480px，靠近屏幕右缘时可能超出（H05 的 `minX` 只夹了左侧）。
3. **[低] 「移动」按钮语义**：主路径是直接拖拽，按钮打开的是数值精调浮层，需要在 title 里写明。
