### H43 点击学习入口后一颗暖金小星落下、柔光消散、展开小窗（500–800ms，一次打开最多一次）

- **要求**：点击学习入口后，一颗暖金、圆润绘本风小星从天空缓慢落到窗口锚点，柔光消散并展开小窗；建议 500–800ms，一次打开最多一次，不等待后端响应才结束。
- **前置依赖**：H39–H42（窗口与内容）。

#### GitHub 候选对比与已读源码
- 通用做法：入场动效用**纯 CSS keyframes + 一个 DOM 覆盖层**，不挂 3D 场景、不阻塞数据请求；且只在「从无到有打开」时播一次。
- 本项目：`.star-fall` 覆盖层（`pointer-events:none`），`.star-core` 从 `-42vh` 落到 0 并淡出（700ms `cubic-bezier(.22,.9,.25,1)`），`.star-halo` 柔光扩散消散；窗口在动画结束后才挂载（700ms 计时器）。

#### 第一遍实现
- `SpaceApp.open()`：当「之前没有面板、现在打开的是 focus 面板」时触发 `setStarFall(true)`，700ms 后 `setStarFall(false)`；`focus` 计算里带 `!starFall`，所以星落期间窗口不渲染。
- 动画完全独立于 `/api` 请求，不等待后端。

#### 第一遍审查（主动构造失败）
1. **[中] 「一次打开最多一次」的判定**：若用户在窗口已开时再点同区块，不应再播星——用 `!prev && FOCUS_PANELS.includes(...)` 判定，已在复审验证第二次点击无星。
2. **[低] 动画期间无窗口，也就没有关闭按钮**：用户只能等 700ms（可接受），连续点开会走 `cancelStar` 立即开窗（见 H44）。
3. **[待验] 视觉是否「巨大炫光盖住内容」**：需 vision 复核。

#### 第二遍实现（补 #3 视觉证据）
- 用 `.dsh-tools/h43-star-shot.py` 在动画中段（260ms）截图并 vision 复核。

#### 复审
- `.dsh-tools/h43-star.py`：
  - **点击后 120ms：`star=1, core=1, sparks=3, focus=0`**（星在、窗未开）；
  - **870ms 后：`star=0, focus=1`**（窗已展开）；
  - **0 → 窗口出现 ≈700ms**（符合 500–800ms）。
- **vision 复核**（`h43-star-mid.png`）：「画面中有一颗暖金色小星、位于半空朝向屏幕中央下落、**没有巨大炫光盖住画面**」✓
