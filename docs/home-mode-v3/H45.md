### H45 动画期间最多一个轻量粒子/星对象与少量光点

- **要求**：动画期间最多一个轻量粒子/星对象与少量光点，不持续落星，不用巨大炫光盖住内容。
- **前置依赖**：H43（星落动画）。

#### GitHub 候选对比与已读源码
- 轻量入场的分寸：**一个主粒子 + 少量火花**，用 CSS 动画（不是每帧 new 对象、不是粒子系统），且一次性播完即消失；避免全屏亮白闪。
- 本项目：`.star-core`（1 个）+ `.star-halo`（柔光，扩散即消散）+ `.star-sp` × **3**（固定 3 个光点）；全部 `animation` 一次 `forwards`，700ms 后覆盖层直接卸载。

#### 第一遍实现
- 覆盖层 `.star-fall` 仅在 `starFall` 为真时渲染（700ms），`pointer-events:none` 不挡交互。
- 星星为 26px 圆点 + `radial-gradient` + 24px 柔光阴影；`.star-halo` 120px 渐变在 700ms 内从 0.2 放大到 1.55 倍并淡出到透明。
- 没有粒子系统、没有循环动画、不持续落星。

#### 第一遍审查（主动构造失败）
1. **[中] 「巨大炫光盖住内容」的风险**：`.star-halo` 半径 120px、峰值不透明度 0.85——需 vision 复核是否刺眼/遮挡。
2. **[低] 光点数量**：固定 3 个，符合「少量光点」；不随窗口数量增加。
3. **[待验] 动画结束后是否残留 DOM**：需确认 700ms 后 `.star-fall` 从 DOM 移除。

#### 第二遍实现（验证 #1/#3）
- 复审：动画中段 vision 复核 + 870ms 后 DOM 中 `.star-fall` 数量为 0。

#### 复审
- `.dsh-tools/h43-star.py`：120ms 时 **`star=1, core=1, sparks=3`（恰好 1 星 + 3 光点）**；870ms 后 **`star=0`**（DOM 已卸载，无残留）✓。
- **vision**（`h43-star-mid.png`）：「一颗暖金色小星、半空下落、**没有巨大炫光盖住画面**」✓
- **状态**：**双轮通过**
