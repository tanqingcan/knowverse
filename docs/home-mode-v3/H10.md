### H10 球面局部坐标移动、整周可达、贴地不浮空

- **要求**：移动使用球面局部坐标/地形采样，整周可达；背面、接缝、极点操作稳定，贴地对象不浮空。保留泥土与道路沿曲面弯曲能力。
- **前置依赖**：H02/H09（实例 + 锚点）。

#### GitHub 候选对比与已读源码
- 复用 `docs/home-editor-references.md`：**drei PivotControls**（MIT）文档明确「普通 XYZ 位移不能直接作为球面移动，需投影回地形并重算法线」——本项目用 `capFrame(x,z,yaw,lift)`：`surfaceFrame` 给出 `pos = n * (R + lift)` 与 `quat`（局部 Y = 法线），拖动时把相机射线与球面求交再 `pointToCap` 投影。
- 对比 three.js `TransformControls`：其世界空间位移在本项目会浮空/穿模，故**不采用**，只借其「拖动期间暂停相机」的机制（H11 复用）。

#### 第一遍实现
- 几何能力已在既有 `surfaceFrame/capFrame` 中；本轮**补齐可验证性**：新增 `tests/unit/sphere-reach.test.ts`（5 例）。
- `GardenWorld` 的拖动已走 DOM `pointermove` + 相机射线×球面求交（H02 修复），对象位置来自 `capFrame`，恒定贴球面。

#### 第一遍审查（主动构造失败）
1. **[中] 竖直家具在赤道附近硬直立**：`OnCap` 的 `upright` 直接向世界 Y 插值（长椅/路灯/木牌），在球体下缘法线接近水平时会与地表穿插/看起来「站不住」。
2. **[待验] 背面/接缝/极点稳定性**：只有肉眼观感，没有数值证据。
3. **[中] 泥土/道路曲面弯曲**：由 `SphereSurface` 顶点投影保证（G3 已有 20000+ 顶点半径测试），本轮未回归。

#### 第二遍实现（修复 #1 + 补 #2 证据）
- `OnCap` 的竖直插值系数改为 `upright * cos(polar)`：靠近北极完全竖直，赤道附近完全贴合法线，避免穿插。
- 新增数值测试 `sphere-reach.test.ts`：
  - 15 组极值坐标（含极点 [0,0]/[0.001,0.001]、四个正向极值、对角线、±4 超舒适区）→ `pos.length()` **恒等于 PLANET_R ± 1e-6**（不浮空不陷地）；
  - 局部 Y 轴与球外法线点积 **> 0.99**（背面/极值也成立）；
  - yaw 只绕法线转（半径与上方向不变）；
  - 24 点绕一圈方位角覆盖 0–360°（≥11/12 个 30° 桶）；
  - lift 只抬升半径、不改朝向。
- 修改文件：`src/components/world/GardenWorld.tsx`、新增 `tests/unit/sphere-reach.test.ts`。
