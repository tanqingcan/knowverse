### H19 E / 「全部素材」打开分类物品库

- **要求**：E 或「全部素材」打开分类物品库，展示全部登记资产；检索、分类、缩略图、加入/替换快捷槽，关闭回到星球。全量库只在主动打开时遮挡场景。
- **前置依赖**：H16/H17（底栏 + 隐藏原 UI）。

#### GitHub 候选对比与已读源码
- 复用 `docs/home-editor-references.md`：**fernforge-arcade/minecraft-clone（无 license，仅交互）** 的「E 打开全量物品栏、槽位与物品库分离」；**KolyaVol（MIT）** 的素材库为独立浮层。
- 本项目实现：左侧 `CreativePalette` 从「常驻侧栏」降级为**按需覆盖层**（`libOpen` 才渲染），检索/分类/缩略图沿用既有实现（21 种可放置素材）。

#### 第一遍实现
- `SpaceApp`：`libOpen` 状态；`CreativePalette open={creativeOpen && libOpen && !focus}`；`E` 键打开；「全部素材」按钮打开；`Esc` 先关库。
- 关闭库（`onClose`/选完素材 `onSelect`）→ `setLibOpen(false)` 回到星球。
- 全量库只在 `libOpen` 时渲染 → 未主动打开时不遮挡场景。

#### 第一遍审查（主动构造失败）
1. **[中] 入库后选素材没有关闭库**：`onSelect` 原本只设 placingKind，库仍盖在星球上，用户看不到放置预览。
2. **[中] 「加入/替换快捷槽」未实现**：库内只有「选中即放置」，没有把素材写进 9 槽配置——该能力归 H20，需明确记录。
3. **[低] Esc 层级**：库打开时 Esc 必须先关库（不能直接退出创造或清空选中）。

#### 第二遍实现（修复 #1/#3）
- `onSelect` 增加 `setLibOpen(false)`（选完素材立即回到星球并进入放置预览）。
- Esc 层级加入 `libOpen` 分支（见 H18 实现）。
- 修改文件：`src/components/space/SpaceApp.tsx`。
