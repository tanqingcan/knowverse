### H48 窗口开关不卸载重建星球、不重播入场、不丢失未发送输入；失败可重试

- **要求**：窗口开关不卸载重建整个星球、重播入场或丢失未发送输入；对话请求失败可重试。
- **前置依赖**：H39–H47。

#### GitHub 候选对比与已读源码
- 浮层/沉浸阅读的常见错误是「打开面板就把主场景 `display:none` 或卸载」，导致重绘、入场动画重播、3D 资源重建。正确做法是**主场景常驻、只切换布局类**。
- 本项目：`.is-focus .world-wrap` 仅改 `inset/border-radius` 等样式，`GardenWorld` 仍挂在同一个 `<Canvas>` 上；面板是覆盖层而非替换层。

#### 第一遍实现（核查现状）
- 用 canvas 元素上的随机 `data-probe` 标记同一颗 canvas，比较「打开前 / 窗口中 / 重开后」的 probe、canvas 数量与相机 yaw。

#### 第一遍审查（主动构造失败）
1. **[高] 未发送的草稿会丢**：在输入框打一段字 → 关窗 → 重开，输入框变回空。面板卸载后 `useState` 草稿状态随之丢失。
2. **[中] 「失败可重试」未验证**：发送失败时错误提示会显示，但输入内容是否回到输入框未验证。
3. **[低] 入场动画是否重播**：星球常驻即可保证不重播，需以 probe/yaw 证据支撑。

#### 第二遍实现（修复 #1/#2）
- `ChatPanel` 草稿持久化：按会话 key `kv-chat-draft:${conversationId ?? "new"}` 存 localStorage；`setDraft()` 统一写入/清除；发送成功清空、**发送失败把内容放回输入框**（可直接重试）、示例问题点击也写入草稿。
- 修改文件：`src/components/space/panels/ChatPanel.tsx`。
