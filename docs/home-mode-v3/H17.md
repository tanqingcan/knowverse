### H17 桌面底部居中 9 槽快捷栏

- **要求**：桌面底部居中 9 槽快捷栏，圆角哑光绘本风，槽位有模型缩略图、数字、选中边框和短名称提示。不是左侧常驻长素材表。
- **前置依赖**：H16。

#### GitHub 候选对比与已读源码
- 复用 `docs/home-editor-references.md`：**fernforge-arcade/minecraft-clone（无 license 声明，仅借交互）** 的「底部槽位条：数字键 + 缩略图 + 选中高亮」与 Minecraft HUD 的槽位形态；**KolyaVol（MIT）** 的编辑器底部工具栏同为居中一行。
- 本项目适配：新建 `CreativeHotbar`（不引入任何依赖），9 槽、圆角哑光深底 + 奶油描边，选中槽用 honey 高亮；缩略图复用 `FlowerSvg`（花卉）与色点（其他）。

#### 第一遍实现
- 新增 `src/components/space/CreativeHotbar.tsx`：
  - `DEFAULT_HOTBAR`（9 类：玫瑰/郁金香/开花小树/灌木/木栅栏/石堆/泥土/石径/暖光书屋）；
  - `CreativeHotbar`：9 个 `.hb-slot`（数字 + 缩略图 + 短名 + `aria-pressed`）、左侧「全部素材」、右侧 撤销/重做/保存/退出；
  - 选中态 `is-active` 边框；放置中显示 `.hb-hint`「点击星球放置 · Esc 取消」。
- `SpaceApp`：`creativeOpen` 时渲染 hotbar 替代左侧面板；`hotbar` 状态从 `localStorage[kv-hotbar]` 读取（9 项 + kind 合法性校验）。
- CSS：`.hotbar`（底部居中、`env(safe-area-inset-bottom)`）、`.hb-slot`、`.hb-dot[data-kind]` 分色等。

#### 第一遍审查（主动构造失败）
1. **[中] 槽位缩略图区分度不足**：非花卉类只有同色圆点，建筑/围栏/道路在 26px 内难分辨；已用 `data-kind` 分色缓解，但「模型缩略图」目标只部分满足。
2. **[中] 快捷栏配置未接入存档**：`localStorage[kv-hotbar]` 只在加载时读取，本轮没有「拖入/替换槽位」的写回（H20 负责）。
3. **[低] 手机槽位压缩**：`@media (max-width:560px)` 把槽位缩到 46×54 并隐藏名称——点击目标 46px ≥ 44px（H24 要求），但未在真机验证安全区。

#### 第二遍实现（修复 #1）
- 增加 `.hb-dot[data-kind]` 分色规则（树/灌木绿、围栏木色、泥土棕、石径灰、石堆灰、灯金、建筑赭），并给每个槽位 `title="数字 · 名称"` 便于识别。
- 修改文件：`src/components/space/CreativeHotbar.tsx`、`src/app/globals.css`。
