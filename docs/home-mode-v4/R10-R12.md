# R10 点对象取背后地形 / R12 创造全程暂停慢转

> R10：**双轮通过** · R12：**双轮通过**

## 一、R10 移动态点对象取背后地形交点

**研究**：three.js 官方示例里 `intersectObjects` 返回的是**被点物体的表面点**；要把"点在物体上但落点在地面"做对，必须用**射线 × 地形（球）**而不是 `e.point`（物体表面）。

**第一遍**：`DecorItem` 的 `onPointerUp` 在放置/移动态先取 `e.ray` 与 `PLANET_R` 球求交（R17 已加 `rayToCap`）。

**审查/复审（真实操作）**：
```
选中资料温室 → M → 移动态点击「花园拱门」→ 确认
移动前 (-0.98, -0.86) → 移动后 (0, 1.3294)
```
- 落点 = 拱门**背后球面**的地形点（0,1.3294 ≈ 拱门底座 0,1.35），**不是**拱门表面点 → R10 要求成立。
- 结论：**双轮通过**。

## 二、R12 创造全程暂停自动慢转（本轮抓到真缺陷并修复）

**研究**：three.js `Editor` 的 `Viewport` 在交互态会停掉惯性/自动旋转；通用做法是"暂停必须由**同一个状态源**驱动所有旋转来源"。

**第一遍缺陷（审查发现）**：`paused` 只传给 `Rig`，而**空闲自转的 `setInterval` 只判断 `mode/reduced/readOnly`，漏判 `paused`** → 实测创造模式静置 5 秒 yaw 仍漂移 **0.0805**（每秒 0.035 × 约 2.3 秒）。

**第二遍实现**：`if (props.mode !== "garden" || props.reduced || props.readOnly || props.paused) return;` 并把 `props.paused` 加进 deps。

**复审（真实浏览器）**：
```
花园（未进创造）静置 5s Δyaw: 0.3009     ← 自转正常工作
创造模式静置 5s Δyaw: 0.0                ← 完全暂停（修复前 0.0805）
DIY 打开期间静置 5s Δyaw: 0.0
拖空白区域后对象坐标不变: True
pageerrors: []
```
- 结论：**双轮通过**。
