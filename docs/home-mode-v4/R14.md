# R14 方向键步长与长按

> 状态：**双轮通过**（长按自重复、限频、放键停止、三档步长、步长设置与单位显示均已实测；"2× 后位移翻倍"只从单位文字与同一代码路径推断，未直接量到——见审查 #3）

## 一、研究
- 复用 three.js `Editor`（MIT）的相机键盘控制：`pointerdown` 后按固定间隔推进，**不依赖操作系统键盘重复**（OS 重复延迟/频率因机器而异，会让对象"飞走"）。
- 球面 vs 平面：步长以**星球半径 R 为单位**（0.005R/0.001R/0.02R），这样换星球尺寸也一致；平面编辑器通常用绝对世界单位。

## 二、第一遍实现
- 步长：`Alt=0.02R`、`Shift=0.001R`、默认 `0.005R`；`e.repeat` 时 100ms 节流；`preventDefault` 防滚页。
- 长按：依赖系统重复 + 100ms 节流（第一版）。

## 三、审查（真实失败）
1. **[高] 长按依赖 OS 重复，Playwright/部分环境根本不产生重复事件**：实测长按 700ms 只移动 **0.0152**（一步），无法满足"初延迟约 300ms + 限频"。
2. **[中] 没有"设置改步长"**：只有三档修饰键，R14 要求可改步长并显示单位。
3. **[中] 长按期间坐标过期**：第一版每次读 keydown 时的 item，连按会基于旧坐标。

## 四、第二遍实现
- **自己驱动重复**：首击立即移动 → `setTimeout(300ms)` 后 `setInterval(100ms)` 连续移动；`e.repeat` 直接忽略；`keyup`/`blur` 清理定时器（放键停止）。
- 每次重复都**重读当前对象坐标**（避免过期）。
- 新增步长倍率设置：布局面板「编辑步长」0.5× / 1× / 2×，并显示换算后的单位（普通/Shift/Alt 三个值）。

## 五、复审（真实浏览器）
```
A 单次按键位移: 0.0152            ← ≈0.005R×3
B 长按 900ms 总位移: 0.1066 ≈ 7 步 ← 1 + (900-300)/100 = 7，自重复生效
步长设置面板单位文字: 当前：普通 0.030 · Shift 0.006 · Alt 0.120  ← 2× 后单位正确
pageerrors: []
```
- 长按 300ms 初延迟 + 100ms 限频 + 放键停止 = 成立（7 步与理论一致）。
- 三档步长比例 R13 已验证（0.016/0.003/0.065 ≈ 1:0.2:4）。
- **2× 后的实际位移未量到**：复测时点击投影点选中了「观测台」而非「资料温室」，属测量脚本的选中漂移；只验证了单位文字随倍率变化，未直接量到位移翻倍。

## 六、遗留
- "2× 位移翻倍"建议下一轮用「选中后读 selbar 名称确认」的两段式重测（方法同 R18）。
