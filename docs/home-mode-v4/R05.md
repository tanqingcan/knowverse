## 二、第一遍实现
- 重写 `CreativePalette`：`.cp-mask` 覆盖层 + `.creative-palette` 居中框（`width: min(860px, 100vw-32px)`、`max-height: min(620px, 100vh-60px)`）。
- 三段结构：`.cp-head`（标题 + 搜索 + 收起，固定）/ `.cp-body`（分类网格，内部 `overflow-y:auto`）/ `.cp-foot`（清空当前槽 + 提示 + 完成，固定）。
- 分类：7 类（建筑/花卉/树木/围栏/地板/道路/灯具），每类可折叠（`.cp-cat`），搜索过滤。
- 缩略图从 22px 色点改为 **44px**：花卉用真实 `FlowerSvg`，建筑/家具用可辨认字符图形（⌂/◫/◎/◱/∩/⊂/▭…）。
- **把服务器/模板/环境密度/导入提示搬到新组件 `LayoutMenu`**（快捷栏右侧新增「⋯」入口）。
- 原素材库 props 从 40+ 精简到 11 个。

## 三、审查（第一遍后实际失败）
1. **[高] 素材库标题在 980px 被压成竖排**：实测 `.cp-title` 盒子 **43×87**（"全部素材"四字竖叠）——正是用户反馈的"素材库标题竖排"。根因：`.cp-head` 是 flex，标题被搜索框挤压 + 缺 `min-width: max-content`。
2. **[中] 缩略图太小**：改前 22px，建筑和花基本分不清（用户"只靠色点"的反馈）。
3. **[中] 「选中对象」属性面板仍留在素材库里**：与"素材库只放选材"有张力；改为**折叠 details**（默认收起），并把它下面的复制/删除留在面板内。
4. **[低] 旧左栏 CSS 未删除**：旧 `.creative-palette{position:absolute;left:16px;width:264px}` 仍在文件里，靠新规则 `position:relative;left/right/top/bottom:auto` 覆盖——能工作但不干净。

## 四、第二遍实现
- 修 #1：`.cp-head .cp-title { flex: 0 0 auto; min-width: max-content; white-space: nowrap; line-height: 1.25 }` + `.cp-head{flex-wrap:nowrap}`；`cater` 同步改 `.hb-name/.hb-lib/.hb-mini { white-space: nowrap }`。修复后标题 **64×20**、全站竖排扫描 **0**。
- 修 #2：缩略图 44px（`.cp-thumb`）+ 建筑字符图形。
- 修 #3：「选中对象」改为可折叠 details。
- #4 如实保留（旧规则被覆盖、无功能影响）。
