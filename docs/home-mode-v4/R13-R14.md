# R13 方向键移动对象（非相机） / R14 步长与长按

> 状态：R13 **第一遍待审**（核心已实测通过；「转镜头 90°/180° 后仍符合屏幕方向」「极点回退」「长按 300ms 初延迟」未验证）
> 状态：R14 **第一遍待审**（三种步长实测比例已对上；长按初延迟/限频未实测）

## 一、研究
- 复用 V3 已读的 **drei `TransformControls`（MIT）**：它在变换期间禁用相机控制（`enabled=false` / 事件生命周期），核心结论是"**对象的变换手势必须与相机的环绕手势互斥**"。本项目没有 drei，但同样的互斥语义可以直接落在键盘分支上。
- **球面 vs 平面差异**：drei `TransformControls` 假设世界 XYZ 轴；本项目对象在球面上，方向键必须按"**当前相机屏幕方向投影到该点的切平面**"，再沿大圆走一小步，不能直接加世界 XYZ 偏置（否则背面/侧面方向会反过来）。
- 新增本项目小工具 `worldToCap()`（`layout.ts`），是既有 `capToAzPolar` 的逆：法向量 → (az, polar) → 球冠平面坐标，用于把切平面位移写回 `x/z`。

## 二、第一遍实现
- 定位：`GardenWorld.tsx:897-900` 的键盘 effect 把 ↑↓←→ 直接写 `drag.current = { yaw, tilt }`（**改相机**，正是用户反馈的问题）。
- 改法：方向键先判断"是否有选中对象"——有则移动对象（回调 `onDecorUpdate`），无则维持原来的相机环绕。
- 步长（R14）：`Alt = 0.02R`、`Shift = 0.001R`、默认 `0.005R`（R = `PLANET_R` = 3）。
- 节流：`e.repeat` 时若距上次 < 100ms 直接返回（上限 ~10 次/秒），避免 OS 极快重复导致飞走；`preventDefault()` 阻止页面滚动。

## 三、审查（第一遍真实失败）
1. **[高] 直接用了 `camera`，但键盘 effect 在 `GardenWorld` 外层组件里**（`camera` 只在 Canvas 内的 `Scene`/`Rig` 作用域）→ `TS2304 Cannot find name 'camera'`。**修**：新增 `nudgeRef`，由 `Scene` 用真实相机基暴露「屏幕方向 → 球冠位移」函数，外层只调用。
2. **[高] 键盘 effect 的 deps 只有 `[props.mode]`**，闭包里拿到的 `selectedDecorId`/`decor` 会**过期**（选中第二个对象后方向键仍操作第一个）。**修**：加 `selIdRef`/`decorRef` 每帧同步。
3. **[中] 极点退化**：正面/背面切平面基可能退化（`tr`/`tu` 长度趋 0）→ 返回 `null` 不动，而不是写出 NaN。
4. **[中] 用滑杆 value 量步长会被 step=0.05 量化**（实测 Shift 步长读成 0.00），改读 `kv-decor` 的精确值。
5. **[中] 用 `.world-selbar` 的屏幕位置验证"屏幕方向"不可靠**：selbar 会被视口边缘夹住（实测 dx=0），这是**探针失效**不是功能失效。

## 四、第二遍实现
- 修 #1：`nudgeRef` 由 `Scene` 注入（`capFrame` → 相机矩阵第 0/1 列 → 投影到切平面 → 归一化 → `worldToCap`）。
- 修 #2：`selIdRef`/`decorRef` 同步。
- 修 #3：退化返回 `null`，调用方保持原位。
- 修 #4：测试改读 `kv-decor`。
- 修 #5：如实记录探针失效，改用"对象坐标变化 + 相机 yaw 不变"作为判据。

## 五、复审（真实浏览器，当前运行版本）
```
选中对象: 资料温室（真实鼠标网格扫描点击选中）
方向键前 坐标(球冠): {'x': -0.98, 'z': -0.86}
ArrowRight 后:        {'x': -0.9648, 'z': -0.86097}
相机 yaw: 0.3320710000000894 -> 0.3320710000000894      ← 相机没动
普通步位移: 0.01617  ≈ 0.005R = 0.015
Shift 步位移: 0.00324 ≈ 0.001R = 0.003   （比例 0.2 = 1/5，与 0.001/0.005 一致）
Alt 步位移: 0.06454  ≈ 0.02R = 0.06      （约 4× 普通步）
未选中时 ArrowRight 相机 yaw: 0.332071 -> 0.452071      ← 无选中仍转相机（回退正确）
pageerrors: []
```
- **用户反馈的"方向箭头控制相机"已修**：有选中对象时方向键移动对象、相机 yaw 完全不变；无选中时才转相机。
- 三种步长比例与设计一致（1 : 0.2 : 4）。

## 六、未验证（不写通过）
- **转镜头 90°/180° 后仍符合屏幕方向**：实测探针（selbar 屏幕位置）被视口夹住失效（dx=0 / 转后 dx=90 但 y 被夹在 4px），**结论不成立也不否定**，需换用"对象世界坐标投影到屏幕"的探针重测。
- **极点回退**：代码有退化保护，但未在真实极点位置构造测试。
- **长按 300ms 初延迟/限频**：代码用 `e.repeat` + 100ms 节流，但未实测长按行为。
- 结论：R13/R14 **保持第一遍待审**，下一轮补上述三项验证并做第二遍修订。
