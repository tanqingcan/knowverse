## 一、本轮定位方法
1. **纯数学互逆验证**（Python 复刻 `capToAzPolar` / `surfacePoint` / `pointToCap`）：
```
(0.3, 0.3)      -> [0.299, 2.97005, 0.299]   -> back [0.3, 0.3]      ✅ 往返精确
(0.0, 0.0)      -> [0.0, 3.0, 0.0]           -> back [0.0, 0.0]      ✅
(-0.9, -0.8)    -> [-0.87603, 2.76156, -0.77869] -> back [-0.9, -0.8] ✅
(0.08968,0.5066)-> [0.08924, 2.95599, 0.50412]   -> back 同值         ✅
```
**结论：坐标映射本身完全互逆，"30px 偏差不是公式错"。**

2. **浏览器里做往返**（新增 `window.__gardenProject(cap)` 探针，真实相机投影）：
```
project({0,0})     = (720.00, 408.66)     ← 北极点在屏幕中心偏上，合理
project({0.3,0.3}) = (841.74, 491.05)
点 (841.7,491.0) → 对象落到球冠 (0.2786, 0.40686)   ← 目标 (0.30,0.30)
球冠误差 0.109 | 再投影到屏幕误差 32.0 px
```
3. **旁证**：R18 用同一探针定位"小屋/树/玫瑰"的屏幕位置去点选，**每次都选到了旁边的「灌木」** → 说明探针的屏幕投影与 Raycaster 的实际拾取**系统性错位**（不是随机误差）。
