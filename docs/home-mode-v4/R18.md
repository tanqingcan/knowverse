## 一、研究
- 复用 R09/R11 的"确认才写一次 + 撤销回原值"；R18 是**覆盖度验证**。
- **球面 vs 平面**：难点在"精确选中特定对象"：`.world-selbar` 会被视口夹住；`__gardenProject` 投的是**脚底**（对象底座在地表），且不同对象高度不同 → 需要按类型给 lift；小物件（花/树/围栏）的射线容易从缝隙穿过或打到后面的大建筑。

## 二、第一遍实现 & 三轮诊断（审计方法修订过程）
1. 第一版：直接用脚底投影点选 → 选中旁边「长椅/灌木」。
2. 第二版：加 `lift` 参数投到对象本体 + 纵向 5 档偏移 → cottage/tree 仍选中「长椅」。
3. 第三版（本轮）：**先点空白清选中 → 等 230–420ms → 点目标 → 读 selbar 名称**的两段式，并按类型试多档 lift。

**诊断结果（关键证据）**：
```
暖光书屋 (1014,291) → 选中='暖光书屋' ✓
资料温室 (404,302)  → 选中='资料温室' ✓
种子小棚 (671,249)  → 选中='种子小棚' ✓
花园拱门 (720,892)  → 选中='花园拱门' ✓
观测台   lift=0.06 → '种子小棚' ✗ ；lift=0.14 → '观测台' ✓   ← lift 必须按对象高度给
小池塘   (720,1387) → 屏幕外（视口 900 高），点不到
长椅/路灯/木牌 → 选中='花园拱门' ✗（小物件射线穿缝，打到后面的大拱门）
```
**结论：投影与拾取本身是对的（4 个建筑精确命中），之前的失败是 lift 不当 + 小物件几何太细 + 部分对象在视野外。**
