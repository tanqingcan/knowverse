# R18 五类型全链验证（鼠标/触屏/键盘）

> 状态：**第一遍待审**（部分子项已实测通过；五类型链的"对象级选中"在自动化下不可靠，未达"独立验证五类型"要求）

## 一、研究
- 复用 R09/R11 已验证的"确认才写一次 + 撤销回原值"机制；R18 是**覆盖度验证**：同一套代码路径在 5 类对象（建筑/树/花/围栏/地面）上是否都成立、互不串动。
- **球面 vs 平面**：无新几何问题；难点在"如何准确地选中某个特定对象"——`.world-selbar` 会被视口夹住、`__gardenProject` 投影的是**脚底**（对象底座在地表，点击容易落到地面或旁边对象）。

## 二、第一遍实现
- 补齐缺失类型：用快捷栏对应槽的「放」+ 点投影点落位 → 树✅、玫瑰✅、木栅栏❌、泥土❌（后两者落位失败）。
- 选中方式尝试过三种：①`__gardenProject` 直接投脚底 ②加 `lift` 参数投到对象本体高度并纵向微调 5 个偏移 ③**网格扫描 + `.world-selbar` 名称**记录每类对象首次命中的屏幕坐标。
- 链：选中 → M → **Esc 取消** → 再 M → 点目标（投影点）→ 确认 → 撤销 → 重做 → 再撤销复原；并比对"其他对象坐标不变"。

## 三、审查（第一遍真实失败）
1. **[高] 用脚底投影点选不准**：点 (841.7,491) 的脚底投影，选中的是旁边的「长椅」/「灌木」——因为对象底座在地表，射线先命中地面或邻近物体。
2. **[高] 加 lift + 纵向微调仍未命中目标类型**：cottage/tree 两次都选中「长椅」。
3. **[中] 网格扫描能命中对象但链内复选不稳定**：扫描成功记录了「玫瑰(320,150)」「资料温室」「泥土/花圃地」「观测台」「种子小棚」5 类，但链内再点同一坐标时 `sel_name()` 与该类型不一致（95ms 采样太短，读到了上一次的 selbar）。
4. **[中] 木栅栏/泥土补齐失败**：`放` 后点投影地表点没有落位（同 R10 的对象/地面命中路径问题）。
5. **[中] 暖光书屋/开花小树未被扫描命中**：扫描网格范围/步长覆盖不足。
