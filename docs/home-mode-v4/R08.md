## 一、研究
- 这是**可用性验收项**，不是功能项：判据是"不用看说明、从花园开始的最少明确操作数 ≤4"。研究重点是**每点一次都在做什么**，参考 three.js Editor（MIT）的"选择 → 属性 → 执行"三段分离：把"选槽"和"执行落位"拆开后，每一击语义单一，才能压到 4 击。

## 二、第一遍实现
- 第一遍的流程（V3 遗留）：点「全部素材」→ 点「放入第 N 槽」→ 选素材 → 关库 → 点槽 → 放置 = **5–6 击**，且要求用户先猜"放入第N槽"。
- R01/R02 改造后：**点槽即进替换**、**点素材即写槽**、**槽上「放」即进放置预览**。

## 三、审查（第一遍真实失败）
1. **[高] 第一遍仍要 5 击以上**：因为入口是"全部素材"再选模式，与 R08 的 4 击目标冲突。
2. **[中] 没有"这一击会发生什么"的可读线索**：用户在库里不知道点素材会不会直接放置（V3 的隐性流程就是这里出问题）。
3. **[中] 测试若用 `document.querySelector(...).click()` 仍是"脚本能点到"**，不满足 R08 的"录完整过程 + 真实点击"要求。
