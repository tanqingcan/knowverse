## 三、审查（真实失败与复现，含我自己的错误）

1. **[高] 用 PowerShell 输出当锚点导致整段替换失败**：`Get-Content` 在 GBK 控制台把中文显示成乱码，我拿乱码当 `replace` 的 old_string → `anchor: 0`，改动没落地（不是"改了没生效"，是**根本没匹配**）。修：改用 Python 以 UTF-8 读文件、用 ASCII 子串/`chr(34)` 拼锚点。
2. **[高] JSX 拼接把自己写坏**：`onSelect` 替换时 `s[:idx] + new3 + s[end+2:]` 导致 `onCancel=` 出现两次（`}} onCancel= onCancel={() => ...`），`tsc` 报 `TS1145 '{' or JSX element expected`。修：补回单个 `onCancel=`。
3. **[高] 提示条插错层级**：`<div className="cp-items">` 出现在分类循环里，提示条被渲染 **7 次**（Playwright strict mode 报 "resolved to 7 elements"）。修：移到面板顶部 `cp-head` 之前，仅渲染一次。
4. **[中] 模板字符串丢引号**：`"空槽"` 在 multiline here-string 里被吃掉引号 → `TS2304 Cannot find name '空槽'`。修：用 `chr(34)` 拼接。
5. **[中] 旧「放入第N槽」按钮仍在**：R01 要求移除隐性开关，当前只是"不再需要它"，按钮本身尚未删除（slotMode 状态仍传到 palette）。
6. **[未验证] 980px 竖排文字**：用户实测的竖排/拥挤属 R06，本轮未处理。
7. **[未验证] 4 次操作可达性**：R08 的步数录音本轮未做。
